Theme 1: Problem Understanding
Problem Understanding & Motivation
The Silent Threat Within Enterprise Perimeters

The Insider Threat Dilemma

  • Perimeter Blindness: Firewalls & WAFs are blind to authorized staff abusing legitimate credentials.
  • Severe Financial Impact: Insider cyber incidents cost enterprises over $16.2M annually (Ponemon Institute).
  • Broad Attack Surface: Disgruntled employees, privilege escalation, and stealthy data exfiltration.

Critical Deficiencies in Existing Systems

  • Static Rule Deficiencies: Rigid thresholds produce false negatives on slow exfiltrations.
  • Black-Box Alert Fatigue: Standard ML flags anomalies without interpretable justifications.
  • Delayed Manual Containment: Security analysts take hours to manually revoke access after damage occurs.
Speaker Script: "Traditional perimeter defenses fail against trusted insiders with valid credentials. Existing tools overwhelm analysts with black-box alert fatigue while lacking immediate containment. Our project unites detection, explainability, and automated workstation quarantine."

Theme 3: Methodology
Methodology & Algorithmic Framework
The Tri-Tier Hybrid Detection Triad

Hybrid Dynamic Risk Formulation

R = 0.45 · Rrule + 0.35 · Sif + 0.20 · Sbaseline

Detection Components

  • Deterministic Rule Engine (45%): Hard threshold bounds (e.g. bulk downloads, off-hours access).
  • Isolation Forest ML (35%): 100 isolation trees detecting multi-dimensional outliers.
  • Z-Score Baselines (20%): Statistical running deviations from personal 30-day mean (μ).

Explainable AI (XAI) Attribution

  • Quantitative Factor Breakdown: Shows exact percentage impact per telemetry parameter.
  • Natural Language Context: Summarizes threat details for rapid SOC triage (< 30s).

Theme 4: Novelty & Containment
Workstation Containment & Audit Chaining
Self-Defending Endpoints & Forensic Non-Repudiation

Automated Workstation Containment

  • Trigger Condition: Dynamic risk score R ≥ 75 (Critical severity).
  • Instant Lockdown: WebSocket broadcasts containment signal (< 250ms).
  • Persistent Lock Screen: Displays "Suspicious Activity Detected".
  • Strict Admin Unlock: Only authenticated Administrator credentials can restore desktop access.

SHA-256 Cryptographic Audit Ledger

  • Forward Hash Linking: Every block links to previous hash: Hi = SHA-256(Hi-1 || Event).
  • Tamper-Evident: Altering or deleting a row immediately invalidates the hash chain.
  • Automated Verification: Built-in verifier processes > 8,400 blocks/second.
